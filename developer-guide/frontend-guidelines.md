# Frontend Guidelines (Bootstrap 5 + Sneat)

## 1. Layout
- Use Sneat layout structure
- Use Bootstrap grid system
- Use cards for data display
- Use modals for create/edit

---

## 2. Tables
- Use Bootstrap table
- Optional: DataTables plugin
- Clean and minimal

---

## 3. Forms
- Always use form-group with label + input
- Use Bootstrap validation classes for error display

---

## 4. JS Placement
- Put scripts at bottom using @push('scripts')
