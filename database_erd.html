Legend:

PK - Primary Key
FK - Foreign Key
italic - Nullable Field

Key Relationships:

  • Users → Central table for authentication and user management
  • Permissions & Roles → Spatie permission system for access control
  • Categories → Sub Categories → Hierarchical ticket categorization
  • Tickets → Main entity linking users, categories, documents, and status
  • Tickets Chronologies → Track ticket workflow and escalation
  • Comments → User interactions on tickets
  • Documents → File attachments for tickets and knowledge base
  • Knowledge Base → Help articles and documentation
  • Subcat Level Pegtugas → Assignment rules for subcategories
  • Audits → Activity logging for all entities
